# Cryptocurrency Price Prediction and Analysis

Этот проект предназначен для сбора, анализа и предсказания цен на криптовалюту, особенно биткоин. В нем реализованы инструменты для парсинга данных, построения моделей и визуализации результатов.

---

## Описание файлов

### all_parserr.py
- Скрипт для парсинга данных по всей криптовалюте.
- Собирает информацию и формирует отдельный DataFrame для дальнейшего анализа.

### best_btc_model (2).txt
- Конфигурация лучшей модели машинного обучения.
- Параметры модели:
{
"learning_rate": 0.0175,
"num_leaves": 99,
"max_depth": 50,
"min_child_samples": 5,
"subsample": 0.686,
"colsample_bytree": 0.929,
"reg_alpha": 1.259,
"reg_lambda": 0.0082
}
- RMSE модели: 209.90

### get_string_prediction.py
- Использует собранные за день данные для преобразования их в строковый формат.
- Необходим для подачи данных в модель предсказания.

### last_candle.py
- Собирает данные за текущий день, такие как последние свечи (candles), для анализа и предсказаний.

### main_updated.py
- Основной графический интерфейс (GUI).
- Предсказывает цену биткоина и помогает автоматизировать открытие торговых позиций.

---

## Как запустить проект

1. Убедитесь, что у вас установлены все необходимые библиотеки Python.
2. Запустите скрипт `all_parserr.py` для сбора данных.
3. Используйте `get_string_prediction.py` для подготовки данных к предсказанию.
4. Запустите `main_updated.py` для визуализации и автоматизации торговли.
